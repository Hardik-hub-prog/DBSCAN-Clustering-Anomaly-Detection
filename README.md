# DBSCAN-Clustering-Anomaly-Detection
DBSCAN clustering on the Iris dataset with anomaly detection and cluster visualization.
DBSCAN (Density-Based Spatial Clustering of Applications with Noise), an unsupervised machine learning algorithm, using the Iris Dataset.

The implementation focuses on understanding how DBSCAN identifies clusters based on the density of data points and detects observations that do not belong to any cluster as noise/anomalies.
